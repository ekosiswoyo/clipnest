# ClipNest app icon

Generated using the built-in ImageGen tool. `AppIcon-source.png` preserves the generated artwork and transparency; `AppIcon.iconset` contains the macOS size variants; `AppIcon.icns` is included by `scripts/build-app.sh`.

## Generation prompt

Use case: logo-brand. Asset type: production macOS app icon for ClipNest, a native clipboard history app. Generate ONE square 1024x1024 icon, not a mockup or icon sheet. A softly rounded macOS squircle tile in deep midnight teal, with a sculpted mint green clipboard silhouette centered, holding two overlapping ivory paper slips; the lower clipboard curves into a simple elegant nest-like cradle with three smooth curved bands. Subtle dimensional ceramic finish, restrained highlights, clean geometric silhouette readable at 32px, generous balanced margins. Front facing, no perspective tilt. Premium friendly native Mac utility aesthetic. Background outside the rounded tile genuinely transparent; tile occupies about 86% of canvas width. No text, letters, watermark, extra objects, surrounding scenery, or cast shadow outside tile.
